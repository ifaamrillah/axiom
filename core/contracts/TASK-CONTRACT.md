# Task Contract

## Required fields

- Task ID and title
- Status and priority
- Owner or responsible agent role
- Scope and explicit out-of-scope items
- Inputs and relevant context
- Dependencies
- Allowed, restricted, and shared file ownership
- Deliverables
- Acceptance criteria
- Verification method and evidence
- Blockers and next action when applicable

## Rules

Tasks must be small enough to execute and verify. Dependencies must be satisfied before work begins. Shared-file changes require coordination. A task is not complete solely because an agent reports completion; the integrator checks deliverables and evidence.

## Suggested status values

Pending, Ready, In Progress, Completed, Blocked, Failed, Cancelled.
