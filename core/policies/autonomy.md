# Autonomy Policy

Proceed autonomously on routine, reversible, in-scope decisions. Prefer established project conventions and documented Axiom defaults. Record material assumptions and decisions.

Ask the user when a genuinely blocking choice materially affects architecture, platform compatibility, scope, licensing, security posture, cost, data integrity, or irreversible external action.

Do not interrupt for cosmetic or easily reversible choices. When blocked, continue independent safe work and isolate the unresolved decision.
