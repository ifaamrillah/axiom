# Task Planning

## Procedure

1. Confirm specification, design, and architecture inputs are sufficiently stable.
2. Break work into small independently verifiable tasks.
3. Identify dependencies and critical path.
4. Assign ownership and allowed/restricted/shared file scopes.
5. Define deliverables and acceptance criteria per task.
6. Select verification layers and integration points.
7. Parallelize only independent tasks with non-overlapping write scopes.
8. Sequence shared-file and integration work.
9. Record risks, blockers, and a realistic completion strategy.

## Outputs

A task plan and dependency view with IDs, ownership, scope, inputs, dependencies, acceptance, verification, and integration order.
