# Routing

| Request | Starting point |
|---|---|
| Unknown or poorly documented repository | `workflows/codebase-onboarding/WORKFLOW.md` |
| New user-visible or technical capability | `workflows/feature-development/WORKFLOW.md` |
| Defect with understood scope | Debugging skill, then relevant implementation/testing/review gates |
| Risk review | Security audit or code review skill, scoped to the request |
| Release preparation | Release management skill and release workflow |
| Single focused question/change | Relevant specialist skill; skip unnecessary workflow stages |

Ask for clarification only when ambiguity materially changes the solution or risk. Keep assumptions explicit and reversible when possible.
