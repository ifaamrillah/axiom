# ADR-0002: License status in the initial design

- **Status:** Superseded by repository state
- **Date:** 2026-11-15

## Context

The initial design discussion had not selected a license. The repository's existing `LICENSE` file on `main` is MIT, committed before this implementation. This ADR records that historical design gap and does not change or reinterpret the license.

## Decision

Retain the existing MIT `LICENSE` file and link to it consistently. This implementation does not modify the license text or claim that its legal status has been independently reviewed.

## Follow-up

The repository owner may review the existing license before a stable release. Do not describe license selection as still pending while the MIT file remains in the repository.
