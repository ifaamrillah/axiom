# Axiom v0.1.0 (2026-11-17)

The first versioned release: 27 engineering skills, an always-on kernel, seven workflows, and a Claude Code plugin, for Claude Code, Codex, OpenCode, and Antigravity.

**Kernel changed:** new. Paste the [Axiom block](../../templates/project/agents-md-block.md) into `AGENTS.md` or `CLAUDE.md` (marker `<!-- axiom:begin v0.1.0 -->`), unless the Claude Code plugin hook loads the kernel for you.

## Breaking

None. This is the first release. Projects that copied Axiom before this release have no version marker; treat them as older than v0.1.0 and follow [Upgrading](../UPGRADING.md).

## Highlights

- **27 skills across the lifecycle:** onboarding, discovery, specs, planning, TDD, debugging, review, security, release, docs. New in this release: `writing-quality`, `performance-optimization`, and `ci-and-observability`.
- **Change proposals:** specs can now change through ADDED, MODIFIED, REMOVED, and RENAMED deltas instead of in-place edits.
- **UI critique:** `ui-ux-design` gains critique, audit, polish, and harden modes and a list of generated-looking patterns to refuse.
- **Claude Code commands:** `/axiom:spec`, `/axiom:plan`, `/axiom:review`, `/axiom:ship`. They load only when you type them.
- **Versioning:** the installed version is visible in the kernel heading, and every release gets a page like this one.

## Other changes

- Offline routing check (`run_evals.py --routing`) and token counts in behavior runs.
- Validator size budget for `SKILL.md` (250 lines and 20,000 bytes).
- Integration notes for code-graph tools and output compressors.

Full list: [changelog 0.1.0](../../CHANGELOG.md#010---2026-11-17).
