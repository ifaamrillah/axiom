# Release Guidance

Use semantic version labels as described in [ADR-0003](decisions/0003-release-versioning.md). Before a release, review the changelog, compatibility status, validation evidence, the existing license, and any unresolved security or migration concerns.

This repository has no release automation. Draft notes using [the release template](../templates/releases/notes.md). Tagging, pushing, publishing, and deployment are separate actions requiring explicit authorization.
