# Workflow Decisions

Record decisions that materially affect scope, behavior, architecture, implementation, or risk. Link durable architectural decisions to individual ADR documents.

| | | | | | |

## Rulings

Minor decisions made during execution so that work does not stall. Each one is reversible and visible to the user at review time.

Format: `R<n> (<date>, <task>): Ruling: <what was decided> — <why> — <cost if wrong>`

- R1 (YYYY-MM-DD, T003): Ruling: …  — … — …

Escalate instead of ruling when the decision is irreversible, security-sensitive, has effects outside the working tree, or changes approved scope.
