# Stage 3: Visual and interaction design

**Skill:** `ui-ux-design` · **Required:** conditional · **Depends on:** stage 1 (and 2 when relevant)

## Entry

Run this stage when the change affects user-facing layout, navigation, interaction, content presentation, or responsive behavior.

## Do

1. Detect the stack and the existing design system (`.axiom/design/MASTER.md` if present).
2. Map the primary flow and every state: loading, empty, error, success, partial.
3. Apply the priority rules (accessibility and interaction first) and record any deviations.
4. Produce flows, a state inventory, and mockups where useful.

## Exit

Interaction and visual expectations are clear enough to specify and implement. Unsupported visual checks are labeled.
