# Stage 12: Delivery and release readiness

**Skill:** `release-management` · **Required:** conditional · **Depends on:** required verification, review, security, and documentation stages

## Entry

Run this stage when the user requests a release or deployment, or when the delivery scope explicitly includes staging or production preparation.

## Do

1. Prepare release notes, a readiness report, staging evidence, and a rollback plan.
2. Attach visual evidence to the PR for user-visible changes when the host supports it.

## Exit

The requested readiness evidence is complete. Production deployment or publishing still requires explicit authorization.
