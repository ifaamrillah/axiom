# Stage 5: Architecture and risk

**Skill:** `architecture-design` · **Required:** yes for cross-cutting or non-trivial work; a short design note otherwise · **Depends on:** stage 4

## Do

1. Check the design against the constitution and constraints.
2. Compare viable options; define boundaries, contracts, data and migration strategy, and security considerations.
3. Record consequential decisions as ADRs.
4. For irreversible or security-critical claims, run an adversarial review of the key claim.

## Exit

The approach satisfies the constraints, and material risks have mitigations.
