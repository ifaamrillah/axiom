# Stage 8: Verification and QA

**Skill:** `testing`, `e2e-testing`, `verification-before-completion`, `spec-analysis` (converge) · **Required:** yes · **Depends on:** stage 7

## Do

1. Run the full required checks; compare against the baseline.
2. Verify user journeys end to end where the change is user-visible; capture visual evidence for UI changes.
3. Run spec analysis in converge mode; implement or explicitly defer any appended remaining work.
4. Check the Definition of Done.

## Exit

Required checks pass with fresh evidence, or a blocker or waiver is explicitly recorded. Regressions are addressed.
