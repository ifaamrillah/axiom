# Stage 11: Documentation and knowledge update

**Skill:** `project-documentation` · **Required:** yes when behavior, configuration, operations, public API, or architecture changes; otherwise record why no update is needed · **Depends on:** stages 7 and 10

## Do

1. Update affected docs with `sources:` and `verified_at_commit:` metadata.
2. Record decisions and ADRs, and add any observed agent pitfall to the project's instructions block.
3. Bring the workflow state up to date.

## Exit

Relevant living knowledge is current or marked as needing review.
