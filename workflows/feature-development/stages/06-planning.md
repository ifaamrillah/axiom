# Stage 6: Planning and ownership

**Skill:** `task-planning`, then `spec-analysis` (analyze) · **Required:** yes for multi-step work; a checklist with `step → verify` for small changes · **Depends on:** stages 4 and 5

## Do

1. Write `PLAN.md`: constitution check, file map, dependency-ordered tasks with exact paths and verification, `[P]` marks, and a coverage map.
2. Run spec analysis (read-only) across spec, plan, and tasks. Resolve critical findings before implementing.
3. Self-check against the Ready for Development standard; set `status: ready`.

## Exit

Every task has scope, a deliverable, acceptance, and verification, and every must-have requirement has a covering task.
