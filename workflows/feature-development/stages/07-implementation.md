# Stage 7: Implementation

**Skill:** `implementation`, `tdd` · **Required:** yes · **Depends on:** stage 6 (or 5 for a small sequential change)

## Do

1. Record the verification baseline before the first edit.
2. Execute tasks in order using the execution loop: inline, or one fresh implementer per task with a two-stage review (spec compliance, then quality).
3. Record rulings for minor decisions and continue. Stop only on the stop conditions.
4. Update the task ledger after each task, with evidence.

## Exit

Every task meets its acceptance with fresh evidence, and no new failures appear compared with the baseline.
